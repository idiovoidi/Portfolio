## How to use this file

- **Level** uses a 1–5 scale: 1 = dabbled, 2 = basic, 3 = comfortable, 4 = strong, 5 = expert.
  Where the site already has a 1–100 self-rating in `skills.ts`, it is shown in brackets, e.g. `(90)`.
- **Status:** `Current` = actively used, `Past` = no longer used (add the year last used).
- **Evidence** points to a project, piece of work or file that shows the skill.
- `TODO` marks things only you can fill in (years, versions, levels, employers). Nothing marked `TODO` has been guessed.
- Rows pre-filled from your portfolio data have a blank Level unless a site rating exists.
